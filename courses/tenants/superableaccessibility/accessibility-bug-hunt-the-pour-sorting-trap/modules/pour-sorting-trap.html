The POUR Sorting Trap

WCAG's four principles — Perceivable, Operable, Understandable, and Robust (POUR) — are the foundation every accessibility guideline is built on. Below, you'll sort real-world examples into the principle they best demonstrate.

A quick refresher

Perceivable

Information and interface components must be presentable to users in ways they can perceive — text alternatives, captions, sufficient contrast.

Operable

Interface components and navigation must be operable — including by keyboard alone, with no traps and no strict time limits.

Understandable

Information and the operation of the interface must be understandable — predictable behavior, clear instructions, helpful error messages.

Robust

Content must be robust enough to be interpreted reliably by a wide variety of user agents, including assistive technologies.

Each principle maps to concrete, testable behaviors. A missing keyboard handler is an Operable failure. A layout that clips content at high zoom is a Perceivable failure. Instructions that don't match what actually happens are an Understandable failure. And a custom widget that assistive tech can't parse is a Robust failure. Keyboard-only instructions

Try completing this activity using only your keyboard — no mouse or trackpad:

  1. Press Tab to move focus to a card.
  2. Press Space to "lift" the card.
  3. Use the Arrow keys to move it toward the correct drop zone.
  4. Press Space again to drop it in place.
  5. Press Escape at any time to cancel and put the card back.
